# URUL web demo

Live demo: https://arancastro.github.io/urul-demo/

URUL is a landslide early warning demo app for Wayanad district, Kerala, built for a
school project. **All data is demo data. This is not a real landslide warning.**

This repository holds only the built web version of the app (Flutter web), shown in a
phone frame on wide screens and full screen on phones. The source code is kept in a
separate private repository; this site is regenerated from it.

Data credits: district outline from DataMeet Community Maps (Census 2011, CC BY 4.0);
basemap © OpenStreetMap contributors (ODbL); Inter typeface (SIL OFL 1.1).
